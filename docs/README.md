# Documentation

This directory contains auto-generated API documentation.

## Generating Documentation

Install Doxygen, then run:

```bash
doxygen Doxyfile
```

Open `docs/html/index.html` in your browser to view the documentation.

## What's Documented

- **FFT Module**: Frequency analysis implementation
- **Scheduler**: Real-time task management
- **Sampler**: ADC simulation and buffering
- **Signal Generator**: Waveform synthesis
- **UART**: Serial communication interface
- **Timer**: Hardware timer configuration

## Documentation Standards

All public APIs are documented with:
- Brief description
- Parameter details
- Return values
- Usage notes
- Related functions
