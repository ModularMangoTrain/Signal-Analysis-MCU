# Signal Analysis MCU

A lightweight RTOS + DSP engine for microcontrollers demonstrating real-time embedded systems and signal processing.

## What It Does

- Generates synthetic audio waveforms
- Simulates ADC sampling
- Performs FFT analysis to extract frequency components

## Technical Stack

- Real-Time Operating System (RTOS)
- Digital Signal Processing (DSP)
- Fast Fourier Transform (FFT)

## Status

Active development. Core functionality implemented.

## Purpose

Demonstrates practical knowledge of:
- Real-time embedded systems architecture
- Signal processing algorithms
- Resource-constrained programming
